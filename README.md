# 隐私政策管理台 · Privacy Policy Registry

轻量级单文件隐私政策管理后台：统一维护各 App 隐私政策链接、留存历史快照、管理 HTML 源文件。纯前端实现，无后端、无依赖，一个 `index.html` 即可部署。

## 功能

- **应用与链接管理**：登记 App 名称、Android / iOS / HarmonyOS 包名、版本号与隐私政策在线链接；定期校验连通性（HTTP 200），失效链接高亮预警
- **快照系统**：上传新 HTML 或检测到在线内容变更时自动生成不可篡改快照（SHA-256 内容指纹 + 哈希链），支持内嵌预览与任意两版本对比
- **文件操作**：上传 / 下载当前生效文件、批量导出历史快照、自定义文件存放域名
- **安全**：首次使用设置管理密码（PBKDF2-SHA256 150,000 轮派生，绝不明文存储）；上传 / 下载 / 删除需 Microsoft Authenticator 六位动态码二次验证；连续失败锁定

## 使用

1. 打开页面 → 首次进入初始化向导：设置管理密码（≥ 8 位）
2. 用 Microsoft Authenticator 扫描二维码（或手动输入 Secret）完成绑定
3. 登录后在「应用管理」登记应用与隐私政策链接
4. 在应用详情上传 HTML、生成快照、下载或导出；「快照库」可预览、对比、删除

## 部署

任意静态托管均可（GitHub Pages / Vercel / Nginx …），将 `index.html` 放到站点根目录即可。建议通过 HTTPS 访问（HTTP 环境下自动启用内置加密后备实现，功能不受影响）。

## 数据与隐私说明

- 全部数据（应用记录、快照、配置）仅保存在**当前浏览器** localStorage 中，不上传任何服务器；请勿在浏览器中清除站点数据，重要快照建议定期用「批量导出」备份
- 更换浏览器 / 设备后数据不会自动同步，可通过「设置 → 数据导出 / 导入」迁移
- 管理密码与验证器密钥加密存储在本地，忘记密码将无法恢复数据

## 技术要点

- 密码：PBKDF2-SHA256（150k 轮）派生校验值 + 认证加密密钥
- TOTP：RFC 6238（SHA-1 / 6 位 / 30 秒），兼容 Microsoft Authenticator
- 快照防篡改：每份快照含内容指纹与链式哈希，可在设置页一键校验完整性
- 加密后备：非安全上下文（HTTP）自动切换内置纯 JS 的 SHA-256 / SHA-1 / HMAC / PBKDF2 实现
